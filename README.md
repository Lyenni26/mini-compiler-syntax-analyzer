# ⚙️ Lexical and Syntax Analyzer (Flex & Bison)

A compiler front-end and syntax/semantic analyzer developed for a formal programming language subset. This project leverages the standard compiler-construction toolchain **Flex** (Fast Lexical Analyzer) and **GNU Bison** (LALR Parser Generator), integrated with a custom symbol table implementation in **C**.

---

## 📌 Features

- **Lexical Analysis (`lexical.l`):** Scans and tokenizes input source code into lexical units (keywords, identifiers, arithmetic/relational operators, numerical constants, and strings).
- **Syntactic & Semantic Parsing (`syntax.y`):** Validates grammatical structure against context-free grammar specifications and triggers semantic verification routines.
- **Symbol Table Management (`ts.h`):** Dedicated hash/linked data structure handling identifier registration, type validation, memory mapping, and variable scope rules.
- **Build Automation (`command.bat`):** Batch automation script coordinating sequential executions of Flex, Bison, and GCC under Windows.

---

## 🗂️ Project Structure

- `lexical.l`: Lexical rules and regular expressions (Flex / Lex).
- `syntax.y`: Context-free grammar specifications and semantic actions (Bison / Yacc).
- `ts.h`: Data structures, hash functions, and primitives for symbol table lookup and insertion.
- `exemple.txt`: Sample input source code utilized to validate compiler parsing.
- `command.bat`: Windows batch script automating the full build pipeline.
- `lex.yy.c`: C source code generated by Flex.
- `syntax.tab.c` / `syntax.tab.h`: C parser implementation and token definitions produced by Bison.
- `projet.exe`: Final compiled binary executable.

---

## 🛠️ Tech Stack

- **Host Language:** C (GCC / MinGW)
- **Lexer Generator:** Flex (Fast Lexical Analyzer)
- **Parser Generator:** GNU Bison (LALR Parser Generator)

## 🚀 Build & Run

### 1. Clone the repository

```bash
git clone https://github.com/Lyenni26/mini-compiler-syntax-analyzer.git
cd mini-compiler-syntax-analyzer
```

### 2. Compilation

- **On Windows (automated script):**
  Run `command.bat` directly or invoke it from your command prompt:
  ```cmd
  command.bat
  ```

- **Manual CLI (GCC / MinGW):**
  ```bash
  flex lexical.l
  bison -d syntax.y
  gcc lex.yy.c syntax.tab.c -o projet.exe
  ```

### 3. Execution & Testing

Feed the test source file into the compiled analyzer:

```bash
./projet.exe < exemple.txt
```
